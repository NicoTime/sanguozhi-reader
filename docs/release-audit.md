# 开源发布审查记录

审查日期：2026-11-08。此记录说明独立开源副本的来源和处理，不改变私人项目或线上部署。

## 已处理

- 核对本地 EPUB 包元数据和 `OPS/about.xhtml`：来源为维基文库，电子版明示 CC BY-SA 3.0 或 GFDL，保留电子版给出的 177 名贡献者；本仓库选择 CC BY-SA 3.0，并记录简繁转换、分段、注锚及其他修改。
- 九卷的正文片段和裴注与原项目有序逐条比较一致，共 932 条（499 段、433 注）。测试样本中的电子文本同样按原版处理。
- 对 12 条 TGAZ 页面逐条核实 CC BY-NC 4.0，逐条列出链接、标明 CHGIS、舍入及非商业约束；保留来源和必要上下文。尚未找到能在保持历史地望依据的同时完全替代这些点位的开放素材，未将可能缺乏出处的地图坐标伪装为独立替代品。
- 现代河流、城市和陆地采用 Natural Earth；地形采用 Mapzen / Tilezen 的 Terrarium 高程并注明 USGS 及变换方法。OpenStreetMap 村落点按 ODbL 标注并链接许可。页面地图区展示相应来源。
- 原官渡旧图包含从历史地图集读取的线形控制点，几何再分发条件没有确认；开源版改为复用项目 v7 依据文字地理关系独立绘制的广域黄河示意，不绘制官渡水线。旧样章提取脚本和原始电子书不纳入仓库。新图只表达大方向，不用于推断岸线、渡口或战场。
- 3 张曹操肖像、104 张场景图依据生产记录为 OpenAI image_gen 生成；曹操及诸葛亮 104 段音频依据生产记录为 ZenMux 调用 Google Gemini TTS。用户选择其有权授权的原创解读、音画采用 CC BY 4.0；生成资产与 SHA-256 清单见 [generated-assets.sha256](attributions/generated-assets.sha256)。对版权不产生的素材不虚构排他权利；输出仍需遵守适用服务条款和第三方权利。
- 保存源码、独立构建配置、章节数据、地图、正式音画、必要编排和测试。原 EPUB、试听候选、原始录音、缓存、构建产物、私人服务器配置和原项目 Git 历史均不纳入。

## 仍有的边界

1. **部分历史地名数据限制非商业使用**。程序代码 MIT 不覆盖它们，整套项目不能宣称完全可商用。要消除此限制需逐项寻找可复核地望、来源清楚且许可兼容的替代资料，或获得权利人授权。
2. 维基文库各卷的线上当前版本可能与 EPUB 快照不同；本项目保存源卷哈希和 EPUB 附带的贡献者名单，不把不同版本冒充独立校勘。
3. 本地电子版注明简体转换，未附带独立转换过程记录；按电子版声明及来源处理，保留转换与改编说明。
4. 地形瓦片由多个上游数据源构成，复用者应按 Tilezen 所列来源及相应地区核对具体使用条件；不能把派生地形笼统标为 MIT。
5. AI 图片和音频为艺术演绎；相关授权只在作者有权授权的范围内适用，服务商条款与生成内容的独立版权资格不能互相替代。音频技术检查不代表逐句听审。
6. 本仓库应在全新检出的环境里安装、测试和构建后再推送；工作区已有原项目的个人部署资料不属于本仓库。
