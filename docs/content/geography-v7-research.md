# v7 三国志地图：史料、数据与许可研究

研究日期：2026-11-06。状态：**方案与数据可行性研究；尚未生产历史地理图层，也未获数据分发授权**。目标是中国范围可总览（含台湾岛），并能理解汉末至三国时期州郡、治所及自然地理，不把现代底图冒充古图。

## 决策建议

1. **先做全国物理底图，再逐层叠加可证实历史信息。**建议全国视野大致覆盖东经 73°—135°、北纬 3°—54°，兼顾大陆、台湾岛、海南及南海方向；常用视野可适当裁切，另以缩略视图表示南海诸岛。实际投影、容器比例、地图包围盒与多端布局由开发验证，不能以经纬矩形计算替代窄屏实际验收。台湾岛显示“台湾”（现代对照标签），与任何古代行政面或政权面解耦。
2. **先以 208 年和 262 年作为两个独立参考截面**：前者贴近汉末，后者是蜀汉灭亡前的三国并立截面；[日本国土地理院馆藏地图](https://www.gsi.go.jp/common/000053613.pdf)可见 208 年标注，[OSGeo 中国中心的三国地图说明](https://maphub.cn/map/m0346/)明确标注 262 年。两者仅作研究和校勘入口，尚未确认其图片或底图的数据再利用授权；并非批准复制。不要把两截面当作对 208—262 每年的连续复原，也不要将 262 年的州郡用于 208 年片段而不提示。先选择有证据的节点，实际可交付数量取决于逐项校核与许可。
3. **以州、郡、治所分层，承认时变与空白。**全国层以少量州名和政权大致范围辅助定位，区域层再展示经核验的郡名与州郡治所点；县以上层级名称不等同于严密可测的边线。战乱中的控制、名义行政隶属和实际驻治应分开；缺证时以标签、点或文字说明展示，空白不代表无人或无政权。不要从现代省界推古州郡线，也不要以治所 Voronoi 自动生成行政范围。
4. **历史水系与现代底图分层。**先交付有清楚标识的现代海岸线、河流、湖泊，以及有证据时的少量历史河段/湖泽“示意”；单独显示来源、时段和不确定性。无法核实位置或重分发权的古长江、古黄河、大湖及古东海岸线不能画成完整、精确的复原图。尤其不能将现代东海岸线改名“汉末海岸线”。
5. **研究与发布分开。**本报告给出可实施顺序，但真实历史边界矢量与历史水系矢量的公开重分发来源仍未解决。公开版第一步可交付现代地理参照 + 自主校核的少量历史名称/治所；完整历史州郡面和河网需单独获得合适许可及史料复核后再发布。

## 地理证据及不确定性

- **黄河**：研究指出东汉治河后形成的东汉故道经魏晋相对稳定，且不同阶段与西汉北流、后世南流不同；详见[黄河中下游 2000 年环境研究](https://www.resci.cn/article/2020/1007-7588/1007-7588-42-1-3.shtml)和[中央民族大学关于历史黄河河道研究的讲座摘要](https://history.muc.edu.cn/info/1021/4226.htm)。这足以否决直接使用现代下游线作为古河道，却**不足以从本文凭描述得到可发布的全线坐标**；须找获准发布的时段线路、原始证据和标绘误差。
- **长江与湖泽**：[《地理学报》两千年环境变化研究](https://www.geog.com.cn/EN/abstract/article/0375-5444/49025)讨论了荆江河道和洞庭湖长期变化。湖面有季节及年代差异，“云梦泽”“洞庭”与现代水体不能按今日湖岸简单描边；不要用单一巨大蓝色多边形假称某年定界。文章结论本身不授权直接复制其图片或几何。
- **东部海岸线**：淤积与河口变迁存在地域及年代差异；本轮未找到适用汉末—三国且可公开再分发的全国古海岸几何。可显示现代海岸作为参考并明确标注；古海岸保留未覆盖状态，若有逐段授权、证据和时间范围再加虚线或不确定带。
- **230 年夷洲**：《吴主传》黄龙二年记孙权遣卫温、诸葛直率军浮海寻找夷洲、亶洲；同条后续写亶洲远不可至、军队经岁后从夷洲带数千人返回。它直接证明的是文本记载的航海事件，不提供现代坐标、登陆点或行政建置边界。[周婉窈论文](https://homepage.ntu.edu.tw/~wanyaochou/paper/Ming%20People%27s%20Knowledge%20of%20Taiwan.pdf)讨论夷洲、夷州与后世辨析；有研究将夷洲视为台湾，亦有学者质疑证据是否足以确定（[LSE 收录论文](https://researchonline.lse.ac.uk/id/eprint/124781/2/14816169_Taiwan_Culture_Research_Programme_Taiwan_in_Comparative_Perspective_vol_4.pdf)）。建议文案：“夷洲可能与今台湾有关，具体对应有争议”；不画精确航线、登陆点或把台湾填为当时吴郡县。台湾作为现代地理参照始终可见，古今地名判断另列弹层。

## 建议数据契约（待主会话确定）

- **图层**：`id`、`kind`（现代物理/历史水文/州郡/治所/政权示意）、`label`、`geometry`、`sourceIds[]`、`licenseId`、`attribution`、`version`、`derivation`、`validFromYear`/`validToYear`、`temporalPrecision`（快照/区间/未知）、`spatialPrecision`、`confidence`、`uncertaintyNote`、`displayLabel`。支持 `geometry: null`，以无地理位置的史料条目表达未知；数据分发权单独记录，不以 confidence 代替许可。
- **行政实体**：区分 `jurisdictionName`、`level`、`nominalAffiliation`、`controlStatus`、`seatPlaceId`、`validFrom/To` 及各自证据。名称、行政辖区、实际控制、首府治所不是同一概念；政权控制范围的虚线和行政层级要分开开关与图例。
- **水系/海岸**：`featureType`、`basis`（现代观测/历史推定）、`period`、`geometry`、`uncertaintyArea` 或说明、`sourceIds`；时段不明就保持未知。不得把现代河流自动并入历史主图并冠以古名。裁切、合并、简化必须留痕并确保许可允许。
- **治所**：除地点名外标明“治所参考点”，支持 `approximate-area`/`uncertain`/`unlocated`，无坐标不显示假点；不要用精确经纬度表现未经证实的城门、驻军或水岸位置。
- **图层交互**：全国/地区切换、台湾可见性、现代参考层和历史示意图例、缺证提示、来源入口；对移动端、色盲和键盘操作另立验收。九篇地名未进行穷尽抽取，不应据此宣称全国覆盖已完成。

## 后续检查与阻塞

1. 收集可发布的 208/262 州郡及黄河、长江、湖泊、海岸几何，逐一取得具体授权或确认可分发来源；记录版本、原 URL、校核日期、修改方式。
2. 以少量治所作试点，逐点核实年代、同名和真实坐标精度；处理同名异地、同一州多政权及治所迁移。不是所有州郡都必须有可绘边界。
3. 遍历九篇具有明确年代/地理意义的段落；先验证按场景切换时的时段有效性、证据和地图归属。浏览器实际校验包括全国视野、台湾标签、图例、无证空白、窄屏与离线构建大小。
4. 本文尚未进行 GIS 图层下载、原始几何验收、许可函核实或发布；以上为来源与契约研究，不构成浏览器验收或生产授权。

## 与 v0.7 实施计划和最新协调的衔接

主会话倾向以 **200 年和 262 年**为独立断面，可行；本报告最初列 208 年只是有现成地图目录可查的候选，不能把 208 年图层未经校对当作 200 年。200 年应以原文与具备具体证据的州郡名、治所及现存研究逐项核验，不能先假定东汉各州均受同一势力控制；262 年应按魏、蜀汉、吴分别核实各州名、部分郡名及治所，蜀地与荆扬边缘用淡色范围、虚线和不确定注记，不用点位推算边界。断面之外显示“参考 200/262 年”，不得伪称对应每个阅读年份。具体郡县或治所迁移需逐项来源，缺证不生成。

对于“实际可理解的大致划分”，可用原始文字所述的相对方位与区域范围，**独立构造原创的低精度示意轮廓**，不照描受限图件或拷贝 CHGIS 几何；每一面均需记录可查来源、依据、绘制方法、时间和不能代表精确界线。先做少量能解释的州区，再逐个扩展；空白不作实际控制判断。判定需要可分发几何的许可时，不能以“自主描绘”为由绕过受限图的著作权与数据库权利。

黄河 69 年后东汉故道方向可参考[威海市水务局材料](https://slj.weihai.gov.cn/art/2020/10/27/art_2632_2424837.html)及[资源科学研究](https://www.resci.cn/article/2020/1007-7588/1007-7588-42-1-3.shtml)。主会话还提供[宁夏水利部门材料](https://slt.nx.gov.cn/slxc/jswm/wxwh/202407/t20240731_4610537.html)作为王景河经濮阳南、范县、莘县、阳谷、东阿至利津的待复核材料；本次该页面抓取返回 405，具体所列路径未独立核实。后续可据可核验文字的相对位置独立画宽泛示意并清楚说明，避免精确岸线外观；来源无法支持的段落须留空。黄河与长江是不同主河，不画成一条主河；如展示运河应单独标示人造水道、时间和证据。

长江、主要湖泽及东部海岸的古环境仍应按计划交付有证据的概略图层，但目前来源只支持各别定性认识，不能凭现代全线换名；后续应优先逐段从史料及研究获得能用于原创、示意的可靠空间关系，不能核实的段落及湖岸保持空缺并说明。图层建设不等待“精确古界”，但任何实际投放的示意仍需逐对象时间、依据和不确定性记录。
