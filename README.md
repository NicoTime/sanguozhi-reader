一款辅助阅读《三国志》原文和裴松之注的静态网页。项目将正文、白话义注、人物和历史地理示意结合起来，并为部分片段提供声音和插画。地图是阅读辅助示意，不代表精确历史疆界或历史现场复原；人物图像和声音为现代艺术演绎。

## 当前状态

这是从现有项目整理出的**代码首发版本**。目前正文、地图、音画及部分脚本和测试材料仍在核对来源与再分发条件；它们暂时不包含在仓库中。**直接克隆本仓库尚不能运行完整网站或通过构建与测试**，可以先访问上方线上体验地址。后续内容发布的具体待办见 [素材与发布审查](docs/release-audit.md)。

## 本地运行（已有完整本地素材时）

需要 Node.js 20.19+ 或 22.12+，以及 npm。下列命令在本项目目录运行：

```sh
npm ci
npm test
npm run build
npm run preview -- --port 4173 --strictPort
```

访问 <http://127.0.0.1:4173/>。开发服务器可运行 `npm run dev`。构建包含数据和音画资源校验，部分检查需本机安装 `ffprobe`；生成的网页在 `dist/`。当前 Git 排除的素材必须先以有授权的方式提供，完整公开发行版尚未准备好。

正文重提取还需要自行准备相应 EPUB，默认路径为 `sources/epub/`，也可通过提取脚本的 `--epub-dir` 参数指定；项目不附带原始 EPUB。提取脚本支持的是项目使用过的特定电子版本结构，不保证适用于其他版本。部分旧样章提取脚本尚未公开。
