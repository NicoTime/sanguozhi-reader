# v0.7 地理数据首批交接

2026-11-06；配合 [研究报告](geography-v7-research.md) 和主计划第 7 节。数据文件为 `public/data/atlas-v7/manifest.json`、`features.geojson`；仅新增资源，未改旧章节或提取器。研究和数据制作完成，尚未进行浏览器或公网验收。

共 60 个要素：29 个州级区域示意面、19 个治所或城市参照点、2 条历史河流方向线、4 个历史湖泽示意、1 条苏北黄海古岸示意和 5 个现代岛屿/海域标签。200 年断面有 13 个州区符号，262 年断面有 16 个。区域面依据文字地理关系自绘为不规则低精度示意，反映相邻方位；它们不是完整的行政边界或控制范围，也不意味着未涂色的地方没有行政建置。多数两期同名州的几何用于表达相对位置，并不表示两期辖域未变。262 年另列雍州，荆州和扬州区分魏、吴两个地域示意；交趾部／交州在两个断面均有标注，200 年称谓与建置时间的史学争议已写入说明。

两个可核的跨期差异是汉末朝廷所在许县与曹魏都城洛阳（不同政权都城对照，不是同一政权迁治），以及两期荆扬按魏、吴分别示意。后汉书等传统资料与宋书的徐州郯、彭城治所沿革为参考：**宋书没有给出确切迁治年，200 年实际州治存在争议**，故郯只标传统州治参照，不能据此断言 200 年郯→262 年彭城的迁治事实。

地理面依据《后汉书·郡国志》文字、三国正文与后世州郡记载提供的州郡相对方位，在现代地理参考上自行绘制为低精度区域符号；没有追描 CHGIS 或其他历史地图。郡名、政权实际控制及外围地界并未穷尽，亦不由州名反推出边界。治所标点仅代表该地点的大致区域；朝廷/都城点须看 `seatFor` 字段，不一概称为州治。徐州郯点明确注明200年实际治所未定。

黄河下游方向线根据东汉故道东流、通向渤海的研究，自行绘制粗略方向骨架；长江线依据巴蜀、江陵、夏口、九江、建业等地与大江位置关系自行绘制方向骨架。两者均非河槽与岸线复原，不把两条河连为一条；河道弯曲与支流暂不表示。洞庭按秦汉湖泽研究绘成宽泛区域提示；震泽（太湖附近）与江汉云梦泽湖群分别以粗略区域符号展示，不依据现代湖岸描摹，也不将云梦与洞庭合并。古彭蠡在江北九江—黄梅—宿松附近按部分研究作宽泛示意，并标注与现代鄱阳湖的对应仍有争议；均不是湖岸。

苏北黄海古岸只取上冈—盐城—草堰—东台一带作秦汉至南宋长期示意，不是某年岸线。长江口、杭州湾及东海古岸无足够同期证据，暂未绘制；东海标签的说明保留此前古湾研究与汉末未核定的区别。台湾、海南和海域是现代地名与大致位置，不推断孙吴对夷洲或台湾的行政管辖。

初步数据检查：要素 ID 唯一、引用来源及断面均存在、坐标范围合法、Polygon 首尾闭合；共 60 项；14 组所列州区与相关治所／城市参照点做了点在面内的几何自检，包括建业在吴扬州、番禺在交州。点面关系只是视觉一致性检查，不是史实或边界真实性证明。尚未验证底图裁剪、符号可读性、项目图层开关和窄屏渲染。公开数据的引用与研究结论不等于授权复用历史图件，未复制 CHGIS V6 几何；TGAZ 仅引用扬州文字记录，具体页面许可与站内已有数据仍需另行审计。后续如根据证据更新本文件，应同步更新数据版本及校验报告。
